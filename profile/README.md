# civfix

civfix is a social platform aimed at removing friction between communities, volunteer organizers, and local governments. Report issues, organize events, communicate personally with public workers and NGOs to organize accountability and community action for neighborhood issues.

We're built by [Reach Out Los Angeles](https://reachoutla.org), a 501(c)(3) non-profit.

-  **Web:** [civfix.org](https://civfix.org)
-  **iOS:** [ios.civfix.org](https://ios.civfix.org)
-  **Android:** [android.civfix.org](https://android.civfix.org)
  
## Ethos

- Fully free and open source software.
- No ads. No analytics. No trackers.
- GPS and camera info gets stripped from your photos before anything is saved.
- We don't sell your data. We run purely off donations & help.
- Location is only used while you're using the app, and you can still report without it.
